# Shoplifting_Detection
Comparative study of 11 deep learning architectures for shoplifting detection in real retail CCTV footage. Introduces YOLO-MIL-TSwin, a person-tracked Temporal Swin Transformer trained with Multiple Instance Learning, benchmarked against re-implemented baselines (RTFM, Sultani-MIL, CLIP-MIL, ST-GCN) under a rigorous evaluation protocol.
